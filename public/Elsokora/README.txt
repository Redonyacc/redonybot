ELSŐK KORA WEB V2

Feltöltés: az összes fájlt és mappát töltsd fel az /Elsokora/ mappába.

HTML nélkül szerkeszthető:
- Szabályok: data/szabalyok.json
- Karakter történetek: data/tortenetek.json
- Termékek: data/termekek.json

Kép hozzáadása:
1. Tedd a képet az images mappába.
2. A JSON fájlban a kep mezőbe írd be a fájl nevét, például: orion.jpg
